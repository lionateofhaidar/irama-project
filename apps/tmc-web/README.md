# apps/tmc-web

Aplikasi web IRAMA (React + MapLibre + ECharts):
- formulir konfigurasi dan dashboard dasar [T1];
- wizard konfigurasi delapan langkah dan dashboard tiga halaman: Ringkasan Simpang dan Rekomendasi, Arus Lalu Lintas dan Kapasitas, Kinerja Pendekat dan Kualitas Data [T2];
- konsol pemantauan kejadian, CCTV live view, dashboard publik [T3];
- konsol kendali, konsol prioritas, video wall, aplikasi teknisi (PWA) [T4].

Spesifikasi di `docs/planning/15` bagian 5 dan 6.
